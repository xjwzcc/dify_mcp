# 苏州旅游职业学院 · 吴山苑酒店人力资源仿真系统源码

本源码包含教师管理端、学生端（含手机布局）和二者共用的 Node.js 服务端。它们属于同一个完整项目，通过账号身份与服务器权限区分，并非两个互不相通的网站。

## 直接运行

安装 Node.js 24，解压后进入项目目录执行：

```bash
node server.cjs
```

无需执行 npm install，没有第三方运行依赖。Windows 也可双击“启动系统.cmd”，启动脚本会尝试使用本机已安装的 Node.js。

- 本机教师入口：`http://127.0.0.1:8787/?role=teacher`
- 本机学生入口：`http://127.0.0.1:8787/?role=student`
- 其他电脑和手机：将 `127.0.0.1` 替换为运行服务器的电脑局域网 IP，连接可互通的同一网络。

新建空数据库时，默认教师账号 `teacher`、密码 `Hotel2026!`、默认班级注册口令 `HR2026`。公网发布前应设置自己的密码和班级口令。可在首次启动前通过环境变量 `TEACHER_PASSWORD`、`CLASS_CODE` 设置初始值；已有数据库中的账号密码不会被环境变量覆盖。

运行后自动创建 `data/`，SQLite 数据库保存在 `data/hotel.sqlite`。源码包不含当前课堂数据库、已注册学生信息、个人密码配置和服务日志，首次运行建立全新的课堂。保留现有学生数据请在原教师端单独下载数据库备份，按部署指南迁移。

## 源码位置

| 路径 | 说明 |
| --- | --- |
| `public/index.html` | 页面入口、基础 CSS，加载全部界面脚本 |
| `public/app.js` | 员工、招聘、排班、工资、绩效、培训、员工关系等基础业务界面 |
| `public/online.js` | 登录、服务器保存、冲突处理、实时同步、教师总览 |
| `public/teaching.js` | 品牌、教学工单、批阅、教师进度与表现、扩展业务流程 |
| `public/classroom.js` | 教师班级与阶段控制、学生权限界面 |
| `public/mobile.js`、`public/mobile.css` | 手机布局、底部导航、列表卡片、触控表单、角色入口 |
| `server.cjs` | HTTP 服务、认证、SQLite 保存、教师查询、评分与实时推送 |
| `classes.cjs` | 班级、注册、入口与阶段权限的服务端校验 |
| `learning.cjs` | 教学工单、提交、批阅、师生消息接口 |
| `domain.cjs` | 模拟业务初始数据、内置情境任务评分规则 |
| `build.cjs`、`archive/原始离线版.html` | 基础业务脚本与共享规则的生成源；基础 `app.js`、`domain.cjs` 由此生成 |
| `deploy/`、`Dockerfile` | 云服务器、Docker Compose、Caddy HTTPS 部署配置 |
| `test-server.cjs`、`test-classes.cjs` | 独立临时数据库接口测试，不写入正式课堂数据库 |
| `preview-mobile.cjs` | 本机独立手机尺寸预览工具，非正式服务入口 |

教师和学生界面逻辑共用上述脚本，不应把其中几个文件拆开当作独立网站运行。服务端校验负责权限，修改登录网址参数不能获得教师权限。

## 开发与验证

改基础业务时，应同时考虑 `archive/原始离线版.html` 的生成源和 `domain.cjs` 的服务器评分规则，避免后续执行 `node build.cjs` 覆盖直接修改的生成文件。联网、教学、班级、手机扩展分别维护于对应脚本。普通运行不需要重新构建，包内已经包含生成后的可运行文件。

在项目目录运行：

```bash
node test-server.cjs
node test-classes.cjs
```

## 云端部署

请参阅 `deploy/阿里云部署指南.md`。云端使用 HTTPS、持久数据卷和单实例服务，公开入口为自己的域名。源码包中的局域网 IP 或示例域名不能作为新服务器的实际网址。

本仿真系统仅供教学与实训，预置酒店人员和业务数据为模拟数据。
