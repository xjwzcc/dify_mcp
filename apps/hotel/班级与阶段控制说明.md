# 班级与阶段控制

教师登录 [课堂系统](http://127.0.0.1:8787/) 后，左侧选择“班级与阶段控制”。学生须使用教师电脑的局域网地址，不能在自己的电脑输入 127.0.0.1。

## 推荐课堂流程

1. 点击“新建教学班”，填写实际班级名称和首次注册口令，选择“课前关闭”，保存。
2. 上课时选择“讲解观摩”：学生可以进入和查看，不能修改、提交或评分。首次进入选择本班、填写姓名学号并设置个人密码，输入教师提供的本班口令。
3. 分阶段切换为“招聘实训”“排班与薪酬”“绩效与培训”“员工关系”，或“综合实训”。模板可以进一步调整开放模块、业务修改、工单提交和评分开关。
4. 收卷时切换“收卷只读”，保留已保存记录与成绩；需要离场时关闭本班入口。
5. 切换顶部“查看班级”，查看对应班级的任务进度、学生表现、提交批阅与排行榜。工单发布范围可选“所有班级”“指定教学班”“指定学生”。师生互动可向整班或个人发送通知。

## 各开关的含义

| 设置 | 作用 |
| --- | --- |
| 允许本班学生进入 | 控制新登录和已有会话的业务访问；关闭后，已登录学生显示等待教师开放 |
| 允许新生注册 | 只限制首次建号，原有账号仍可在入口开放时登录 |
| 允许业务修改和保存 | 关闭后进入只读；服务器拒绝业务写入 |
| 允许提交工单成果 | 独立控制文字成果提交与重新提交 |
| 允许内置任务评分 | 独立控制四个内置任务的结算评分 |
| 开放模块 | 控制相应业务页面和服务器字段修改；工单提交、评分也检查关联模块 |

班级之间独立配置。服务器每次请求检查权限；已打开页面通常在 3 秒内同步阶段变化。数据仍保存在教师电脑的 SQLite 数据库，重启后班级、开关、学生、成绩继续保留。

## 原账号与保存

- 原学生自动归入“默认教学班”，原密码、存档和成绩保留；默认班首次注册口令沿用原配置。
- 教师可“调整学生所属班级”，保留该学号的原始业务存档和成绩。学号在系统内唯一，学生不能自行换班；换班后按新班权限使用。
- 课间切换前请提醒学生先确认“已保存到服务器”。锁定期间尚未上传的操作保留本机副本；恢复对应模块后可重试保存，或下载个人完整备份。不要清除浏览器数据。
- 迁移旧版完整存档需要全部业务模块和业务修改、评分均开放，且账号尚未开始业务操作。
- 专班工单、整班通知仅向对应班级开放。既有通用工单、历史全班通知继续面向所有班级；需专班使用时，创建指定教学班的新工单。
- “下发课堂任务”为所有班级的通用通知；专班任务请使用“任务工单设计”，专班消息请使用“师生互动”。

升级前数据库备份：`data/before-class-controls.sqlite`。此文件用于恢复，正常启动继续使用 `data/hotel.sqlite`。

## 验证

运行 `node test-server.cjs` 和 `node test-classes.cjs`，测试使用独立临时数据库。覆盖原有实时保存，以及班级入口、口令、注册、只读、模块字段、提交评分、专班工单和消息、归班及重启持久化。

浏览器已验证：新建班级、学生选择班级进入、阶段切换后自动只读、已有会话被关闭入口、重新开放、工单专班发布选项。未使用真实学生账号进行写入测试。
