# 苏州旅游职业学院 · 吴山苑酒店人力资源系统 · 实时联网版

教师端已增加“班级与阶段控制”：多班级独立入口、注册口令、阶段模板、模块开放、只读、提交与评分开关，另支持专班工单和消息。操作步骤见 [班级与阶段控制说明](班级与阶段控制说明.md)。原有学生自动归入默认教学班并保留全部数据。升级后请通过教师端管理各班注册口令；配置文件中的口令仅用于首次创建默认班。

这是包含HTTP服务、SQLite数据库和实时事件推送的可操作系统。学生通过同一个网址进入，教师可实时查看进度、业务记录、绩效面谈和积分，无需导入学习报告。

## 在当前电脑运行

双击 `启动系统.cmd`，浏览器打开 <http://localhost:8787>。需要Node.js 24；当前电脑的启动脚本也支持已安装的Codex附带Node。无第三方依赖，无需npm install。

教师初始账号 `teacher`，初始密码 `Hotel2026!`。登录后可修改教师密码。学生首次登录填写姓名、学号、自设密码（至少6位）与班级口令，默认口令为 `HR2026`；修改配置见下文。已有账号用原姓名、学号和个人密码继续，不因换电脑或清浏览器而重置进度。忘记密码可由教师重置。

如果存在 `登录信息.txt`，以该文件的实际教师密码和班级口令为准，说明此实例已针对公网测试设置独立口令。

同一网络可用启动窗口显示的LAN URL。教师电脑保持开机，校园网须允许设备互通并允许8787端口。公网部署见下文，局域网IP不是公网网址。

## 实时保存与恢复

- 学生业务修改后约180毫秒合并提交，数据库事务成功后显示“已保存到服务器”。教师通过SSE自动刷新，10秒轮询作为补充。
- 全部业务状态在服务端SQLite中按学号隔离，任务分数由服务端读取已保存状态后计算，客户端提交的分数不予采信。它仍是课程实训系统，业务状态可通过开发工具修改，不提供考试防作弊保证。
- 浏览器保存未上传操作副本，网络恢复后重试；刷新页面也会恢复待上传副本。尚未上传的数据无法在另一台设备恢复，因此离开前请确认保存状态。
- 同一学号多个页面修改时，服务器版本号阻止旧记录静默覆盖。遇到冲突，在“处理保存问题”先下载个人完整备份，再选择服务器版本。不会自动合并相互冲突的修改。
- 学生退出会先等待保存。服务器会话持久化，服务重启后可继续登录状态。
- 教师可下载完整数据库备份；服务器另保留每名学生最近20个已保存版本，供管理员恢复。数据库备份含全班档案与密码哈希，应妥善保管。

## 迁移旧版数据

原HTML入口已保留旧版localStorage读取与个人完整存档导出能力。请在**曾经操作的原浏览器、原文件路径**打开该HTML，下载对应学生完整JSON。在网址版建立同姓名、同学号的新账号，尚未做业务操作前进入“情境任务”，导入旧版完整存档。原有成绩由服务器按迁移的业务状态重新核算。旧版“学习报告”只有分数和日志，无法恢复完整业务状态。已被清除的localStorage无法凭空恢复。

## 公网长期使用

可将本目录部署到支持Node 24和持久磁盘的主机，也可使用Docker。根目录必须是本目录，网站入口为 `/`。

```sh
docker build -t lanting-hotel-hr .
docker run -d --restart unless-stopped -p 8787:8787 -v hotel-data:/app/data -e TEACHER_PASSWORD=你设置的强密码 -e CLASS_CODE=你的班级口令 lanting-hotel-hr
```

在反向代理上配置HTTPS及域名，公网实例设置 `SECURE_COOKIE=1`；SSE路径 `/api/events` 需要禁用代理缓冲、允许长连接。单实例运行，不把SQLite文件放在临时文件系统；需要多实例时应改用共享数据库。

已提供 `render.yaml`，可放入你的Git仓库后使用Render Blueprint创建Docker服务，包含 `/app/data` 的持久磁盘。创建时设置 `TEACHER_PASSWORD`、`CLASS_CODE`。持久磁盘与相应实例可能收费，应在平台创建页面确认实际费用。单纯上传HTML或使用不带持久磁盘的静态托管不能提供本系统的数据保存功能。

没有服务器账号时可以通过临时HTTPS隧道测试当前电脑，但电脑关机或隧道停止后网址失效，网址也可能变化。临时隧道不等于长期托管，不承诺持续可用。

## 数据目录与配置

- `data/hotel.sqlite`：正式课堂数据库，WAL模式，事务提交使用FULL同步。
- `data/config.json`：初次启动配置。班级口令可在此修改，重启生效。教师密码仅在数据库首次建号时使用；之后从教师端改密。
- `server.cjs`：登录、存档、评分、课堂任务、教师查询与实时事件API。
- `domain.cjs`：250名员工种子数据、四个任务的服务端判定规则。
- `public/`：实际网站文件，包含全部原业务模块和联网适配层。
- `archive/原始离线版.html`：原版本留档。

备份恢复时先停止服务，将教师端下载的SQLite备份放回数据目录并命名为 `hotel.sqlite`。恢复前应移走旧数据库及相应的 `-wal`、`-shm` 文件并另存备份，避免混用。数据库和配置目录可通过环境变量 `DATA_DIR` 指定。
